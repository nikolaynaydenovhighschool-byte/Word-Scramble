# 🎮 World Scramble

**World Scramble** е забавна десктоп игра, създадена на C# с помощта на Windows Forms (WinForms). Основната цел на играча е да разбере коя е оригиналната дума, скрита зад произволно разбърканите букви.

---

## ✨ Ключови функции и възможности

* 🌲 **Атмосферен дизайн:** Красив и изчистен интерфейс с тъмна горска тема, подходящ за по-дълги игрови сесии.
* ⏱️ **Динамичен таймер:** Всяка дума трябва да бъде позната в рамките на 30 секунди. Ако времето изтече, играта показва вярната дума и преминава към следващата.
* 💡 **Система за жокери (Hints):** Играчът разполага с 3 жокера, които разкриват първата буква от думата. При изчерпване, бутонът се деактивира автоматично.
* ⏭️ **Пропускане на думи:** Опция за прескачане на твърде трудна дума, като системата първо показва правилния отговор.
* 🎵 **Звукови ефекти:** Интегрирано аудио озвучаване със специфични звуци за верен отговор, грешка, изтекло време и пропусната дума.
* 📊 **Брояч на резултата:** Автоматично следене и визуализация на познатите и сгрешените думи в реално време.
* 🔄 **Пълен рестарт:** Бутон за нулиране на резултата и презареждане на списъка с думи от външния файл.
* 📂 **Външна база данни:** Играта чете думите директно от текстов файл (`words.txt`), което позволява лесно добавяне и редактиране на думи без промяна в кода.

---

## 🛠️ Използвани технологии

* **Език за програмиране:** C# (.NET)
* **Технология за интерфейса:** Windows Forms (WinForms)
* **Работа с файлове:** `System.IO` (за зареждане на думите)
* **Мултимедия:** `System.Media` (за звуковите ефекти)
* **Версионен контрол:** Git & GitHub

---

## 🚀 Как се стартира играта

1. Клонирайте репозиторито или изтеглете проекта.
2. Уверете се, че в папката `bin/Debug` (където се намира компилираният `.exe` файл) присъстват следните файлове:
   * `words.txt` — списък с думи (всяка дума на нов ред).
   * `correct.wav`, `wrong.wav`, `skip.wav` — звуковите ефекти на играта.
3. Отворете проекта през **Visual Studio** и натиснете бутона **Start**.
